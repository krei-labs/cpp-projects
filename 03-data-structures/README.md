# 03 - Data Structures

Covers the basic building blocks C++ gives you for organizing data before
moving on to custom/dynamic structures later in this repo.

## Files

| File | Description |
|---|---|
| `arrays_structs.cpp` | 1D arrays, a 2D matrix, `struct` definitions, and an array of structs (student records). |

## Concepts covered

- Declaring and iterating 1D arrays
- Passing arrays to functions
- 2D arrays (matrices) and nested loops
- Defining a `struct` to group related fields
- Arrays of structs, and formatted table output with `<iomanip>`

## How to build and run

```bash
g++ -std=c++17 -Wall -o arrays_structs arrays_structs.cpp
./arrays_structs
```
